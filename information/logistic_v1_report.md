# Logistic v1 兵种克制实验报告

## 协议

- 数据：dense v1，固定 train/validation/test = 770/96/96 局切分。
- 特征：main（86 维）、interaction（43×43=1849 维）、combined（1935 维）；每局同时使用双方视角。
- reward：beta=0.3；所有已知胜负（含投降与终局）均为 ±100，null 为 0；按剩余有效回合最大绝对值归一化为软标签。
- C 仅按验证集交叉熵选择；测试集使用 canonical replay group 的 5,000 次 cluster bootstrap。
