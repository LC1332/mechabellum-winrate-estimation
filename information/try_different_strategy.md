# 策略1 加入spatial pooling

在我们原本的模型中

w_ij a_i b_j 没有考虑空间的对位

这里我们考虑在战场中增加一些探测点

默认是M = 3个
(-300,0) ; (0,0); (300,0)

这个时候所有的兵会先计算自己的价值

自己价值 = 购买费用 + 等级费用 + （科技+解锁）/N

其中N是同样这个单位在我方的数量

a_i 会被拆分为 a_i,1 ... a_i,m ... a_i,M
这些分量的和仍然等于a_i

每个兵会计算到M个探测点的距离 d_1, ... d_M

并且根据距离 有一个指数衰减 （半衰距离默认为300，帮我测试150，300，600的情况）
累积到a_i,m上

这样可以分别计算出每个兵种在每个点的投入比例

整体会计算w_ij a_im b_jm 这样一个值

也就是说这个模型把m点上的对位会分开计算

## 策略2 增加buff特征

游戏有这么几个全局buff

成本控制专家 会导致 攻击减少11%， 血量减少 11%
重装专家 会导致 血量增加 117%
在（research center）tower购买1级别攻击buff 消耗100 会使得总体攻击 增加10%
购买2级攻击buff 消耗300 会使得总体攻击增加 24%
先进进攻战术 卡牌 消耗350 会使得总体攻击增加 30%

同样也有1级血量 2级血量 和先进防御 是作用在血量上的

这里额外增加一个特征 是 单方单位经济占比 * 我方攻击buff ，以及单方经济占比 * 血量buff

也可以考虑 地方单位经济占比 * 攻击buff和地方经济占比 * 血量buff

也就是这个方面的特征最多增加 兵种数量 * 4 * 2 种

## 策略3 将a_i的分母改为公共的

这里我考虑把a_i 原本的分母为我方总经济（以及b_i的分母）
改为双方的调和平均数
也就是 f_ij = A在i上兵种投入 * B在j上兵种投入 / 双方经济之积

总经济总体是稳定的，这个特征在接近原模型的同时 应该能适当反应出双方的总经济之差
